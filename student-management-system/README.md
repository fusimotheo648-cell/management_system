## Project Description

The Student Management System is a responsive web application developed using React and JavaScript. It allows users to view, add, edit, search, filter and delete student records. It includes form validation, confirmation modals, dashboard statistics and browser-based data persistence.

## Technologies Used

- React
- JavaScript
- Vite
- CSS
- GitHub
- Vercel

## Features

- Add, edit and delete student records
- Search and filter students
- Dashboard statistics
- Form validation
- Confirmation modals
- Responsive user interface
- Browser-based data persistence

## Installation and Running

1. Clone the repository.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL displayed in the terminal.

## Deployment
